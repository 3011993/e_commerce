A Modern Android ecommerce application built with Jetpack Compose, demonstrating best practices in mobile development with offline-first architecture and seamless user experience.

## 🚀 Features

- *Product Browsing*: Browse products with category filtering
- *Smart Search*: Fast product search using Trie algorithm with auto-complete
- *Shopping Cart*: Real-time cart management with Firebase Firestore
- *Wishlist*: Save favorite items locally
- *User Authentication*: Secure login/signup with Firebase Auth
- *Payment Processing*: Integrated Stripe payment gateway
- *Offline Support*: Local caching for seamless offline experience
- *Network Awareness*: Connection state monitoring and handling

## 🛠 Tech Stack

### Frontend
- *Jetpack Compose* - Modern declarative UI toolkit
- *Kotlin* - Primary programming language
- *MVVM Architecture* - Clean architecture pattern

### Backend & Database
- *Firebase Authentication* - User management
- *Firebase Firestore* - Real-time cart data storage
- *Room Database* - Local data persistence and caching
- *External REST APIs* - Product data source

### Key Libraries & Technologies
- *Trie Data Structure* - Efficient search implementation
- *Stripe SDK* - Payment processing
- *Network Connection Observer* - Connectivity monitoring
- *Caching Mechanism* - Room-based offline support
